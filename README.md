# Dashboards Without Code

Training materials for **Dashboards Without Code Using Microsoft Power BI: From Data to Decisions**, a 4-hour hands-on session on 12 Nov 2026, 9:00 AM to 1:00 PM MYT.

## What's here

- `board.html`: the session board. A Padlet-style page with one column per block of the day (prep, welcome, Modules 1 to 4, break, follow-up), every activity, checkpoint and Power BI link, plus a minute-by-minute **trainer run sheet** at `board.html#run-sheet`.

Open `board.html` in any browser. No build step and no dependencies apart from the Outfit font from Google Fonts.

## Publishing with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root. The board is then at `https://<user>.github.io/DWC/board.html`.
